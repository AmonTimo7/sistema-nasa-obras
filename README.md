# Nasa Obras — gestão financeira de obras

Sistema web (Django) que substitui a planilha de controle financeiro de uma obra:
lançamentos por categoria, mão de obra com diárias e vales, compras a prazo que
viram contas a pagar, medições com imposto automático, empreitas por metragem,
locações mensais, relatórios e checklist da obra. Visual no estilo macOS.

**Demonstração (dados fictícios, só leitura):** https://amontimo7.github.io/sistema-nasa-obras/
